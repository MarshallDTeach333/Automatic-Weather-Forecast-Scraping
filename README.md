# Automatic-Weather-Forecast-Scraping

I developed a function that automates the process of extracting weather data from a weather app, organizing it into a structured format, and transforming it into a clean, usable weather forecast table. Here's an overview of how it works:

Web Scraping: The function navigates to the weather app’s webpage and scrapes the displayed weather information for each day, capturing details such as date, temperature, precipitation, and wind speed.

Data Storage: The scraped data is stored in a pandas DataFrame, ensuring all relevant weather attributes are systematically organized for further processing.


The result is a clean, structured table that provides a clear and concise weather forecast, ready for analysis or reporting.
